
# AWS Cloud Practical Assessment

## 📌 Project Overview

This project demonstrates practical implementation of AWS Cloud services,
Linux administration, database management, IAM security, and Git/GitHub.

The objective is to understand how different AWS services work together
to deploy, manage, secure, and maintain cloud resources.

---

## ☁️ AWS Services Used

- AWS IAM
- Amazon EC2
- Amazon S3
- IAM Roles
- Amazon RDS (MariaDB)
- Linux
- Git & GitHub

## 🔐 Q1 - IAM

Implemented AWS IAM security and access management.

### Tasks Performed

- Created IAM users
- Configured user permissions
- Tested access and permission restrictions
- Created and used IAM policies
- Verified access using AWS Management Console

---

## 🖥️ Q2 - EC2, S3 & IAM Role

Implemented EC2 instance configuration with S3 access using IAM Role.

### Tasks Performed

- Launched an EC2 instance
- Connected to EC2 using SSH
- Configured Linux environment
- Created an S3 bucket
- Configured IAM Role
- Attached IAM Role to EC2
- Tested S3 access from EC2
- Verified permissions

---

## 🗄️ Q3 - RDS Backup & Recovery

Implemented Amazon RDS using MariaDB.

### Tasks Performed

- Created RDS MariaDB database
- Configured database settings
- Connected to the database
- Created database tables
- Inserted and managed data
- Created database backup
- Tested database recovery
